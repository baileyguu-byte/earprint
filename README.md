# Earprint

Prototype EQ lab: search an artist on Deezer, play 30-second previews, shape the sound with a 10-band EQ, watch the frequency scope, and blind-compare two settings at matched loudness.

## Hosting

Deployed on Cloudflare Pages from this repository.

- Production branch: `main` (deploys to earprint.xyz)
- Any other branch gets its own preview link
- Build command: none
- Build output directory: `public`
